# مشراف — صفحة الهبوط | Mishraf Landing Page

صفحة هبوط لشركة **مشراف** للتسويق الرقمي — HTML/CSS/JS خالص، بدون أي أدوات بناء أو اعتماديات.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## البنية

```
index.html            الصفحة الكاملة
assets/css/style.css  التنسيقات (متغيرات CSS للألوان + استعلامات الوسائط)
assets/js/main.js     الهيدر اللاصق، قائمة الجوال، تتبع الأقسام، ظهور العناصر، النموذج
assets/img/           صور البطل و«عن مشراف»
assets/fonts/         مكان ملفات خط ثمانية (اقرأ assets/fonts/README.md)
```

## الخط

الصفحة مهيأة لخط **ثمانية**، لكن ملفات الخط غير مرفوعة هنا لأن ترخيصه يمنع
إعادة نشرها من غير المصدر الرسمي. التفاصيل وخطوات التفعيل في
[`assets/fonts/README.md`](assets/fonts/README.md).

حتى تُضاف الملفات تعمل الصفحة بـ **IBM Plex Sans Arabic** كبديل تلقائي —
لا شيء ينكسر، والتبديل يحدث بمجرد وجود الملفات.

## الشعار

الشعار مرسوم **SVG داخل الصفحة** (`.brand-mark` في الهيدر والفوتر) وليس صورة:
يتحجّم بلا فقدان جودة، ويتلوّن عبر `currentColor` — بني الهوية على الخلفيات
الفاتحة وأبيض على الداكنة. الأيقونة المصغّرة (favicon) نفس الرسم كـ data URI
في `<head>`.

## المواصفات

- **الاتجاه:** RTL كامل (`dir="rtl"`) باستخدام الخصائص المنطقية (`inset-inline-*`, `padding-inline-*`).
- **التجاوب:** نقاط توقف عند 992px و860px و620px، وقائمة منسدلة للجوال.
- **الألوان:** متغيرات في `:root` مشتقة من بني الشعار `#a67c62`. تدرج الأزرار
  أغمق منه عمدًا ليحقق تباين WCAG AA مع النص الأبيض.
- **إمكانية الوصول:** رابط تخطٍّ للمحتوى، `aria-expanded` على زر القائمة،
  `aria-live` لحالة النموذج، دعم `prefers-reduced-motion`.

## نموذج التواصل

الصفحة ثابتة (static) بلا خادم، لذلك النموذج يتحقق من المدخلات ثم يمرر الرسالة إلى واتساب.
لربطه بخدمة بريد (Formspree أو Web3Forms أو خادم خاص)، عدّل معالج `submit` في
`assets/js/main.js` واستبدل استدعاء `window.open` بطلب `fetch`.

## معلومات قابلة للتعديل

| العنصر | المكان |
|---|---|
| رقم الواتساب | `WHATSAPP_NUMBER` في `main.js` + روابط `wa.me` في `index.html` |
| روابط التواصل الاجتماعي | قسم `.socials` في الفوتر |
| الألوان | متغيرات `:root` في `style.css` |
| الصور | `assets/img/` بنفس أسماء الملفات |
