# خط ثمانية

ملفات الخط **غير موجودة هنا عمدًا**: ترخيص خط ثمانية لا يسمح بإعادة رفع ملفاته
أو إتاحتها للتنزيل من غير المصدر الرسمي، لذلك لا تُشحن داخل المستودع.

## كيف تفعّله

1. نزّل الخط من المصدر الرسمي: <https://font.thmanyah.com>
2. حوّل الملفات إلى `woff2` (اختياري لكنه يقلل الحجم كثيرًا) عبر <https://transfonter.org>
3. ضع الملفات في هذا المجلد بهذه الأسماء بالضبط:

```
Thmanyah-Light.woff2     (أو .ttf)   وزن 300
Thmanyah-Regular.woff2   (أو .ttf)   وزن 400
Thmanyah-Medium.woff2    (أو .ttf)   وزن 500
Thmanyah-Bold.woff2      (أو .ttf)   وزن 700
```

`@font-face` معرّف مسبقًا في `assets/css/style.css`، فبمجرد وجود الملفات
يعمل الخط تلقائيًا. لو اختلفت أسماء الملفات التي نزّلتها، عدّل مسارات
`src` في أعلى ملف الـ CSS.

## قبل النشر

راجع نص الترخيص في الموقع الرسمي للتأكد من أن استضافة الخط على موقعك
كـ webfont مسموحة لحالتك، فالترخيص يمنع إتاحة الملفات للتنزيل.

## حتى ذلك الحين

الصفحة تعمل بـ **IBM Plex Sans Arabic** كخط بديل تلقائيًا — لا شيء ينكسر.
